# 合成大院系

清华大学主题合成小游戏：左右拖动投放院系徽章，两个相同的徽章碰到一起就合成更大一级，直到合出**终极目标**！

候选池共 **29 个**：15 个本科生书院 + 14 个院系（建筑学院[建院]、机械系、电子系[无系]、计算机系[贵系]、交叉信息院[茶园]、自动化系[雷系]、数学系、化学系、工物系、统计系、医学院、经管学院、法学院、美术学院[美院]）。开局标题「合成大院系」，选定目标后合成链 = 目标（链顶）+ 随机抽 14 个未选中的院系；标题规则：两字词「合成大X」（合成大无系 / 合成大经管）、三字词「合成X」（合成数学系）；页面图标与主题背景随目标切换。

> ⚠️ 粉丝同人作品，与清华大学无隶属关系。院徽图片来自公开网络，版权归清华大学及相关权利方所有，仅供学习娱乐。

## 🌑 深色外观的「明亮小球」追踪规则（P4）

点右上角 ☾ 切到深色外观后，全场被近黑遮罩盖住，只有**一颗明亮小球**周围一圈亮着。交棒规则只有四条：

1. **释放即亮**：投下一颗新球 → 这颗新球立刻成为明亮小球。哪怕上一个明亮小球还在空中、还在堆里、甚至正在合成，焦点也归新球，绝不被回头抢走；
2. **亮到被吃掉为止**：一颗球变明亮后一直亮着，不因静止或超时提前交棒；
3. **新明亮小球必须由上一个明亮小球参与合成得到**：只有「明亮小球参与的合成」才产出一颗新的明亮小球；别的球合成的产物一律保持暗着，不接管视野；
4. 明亮小球被移除（合成 / 爆裂）而没有产物时，视野回到投放点，等下一颗球点亮。

因此深色外观下的实际体验是：**顺着亮起来的那颗球去合成**，每次合出来的新球会接着亮着；如果同时丢了两颗球，只有最后丢的那颗亮着。

回归测试见 `test/smoke.test.js` 的「明亮小球交棒规则」小节（释放即亮 / 静止不交棒 / 明亮球合成的产物接管 / 非明亮球合成的产物不接管）。

## ▶ 运行方式

- **方式一（推荐）**：本地服务器，如 `python -m http.server 8000` 或 `npx serve`，访问对应地址；
- **方式二**：直接双击 `index.html`（可玩；仅徽章圆裁可能受 file:// 安全策略降级）。

## 🎮 玩法

- 启动先**选择合成目标书院**（或点「随机目标」）：目标置于合成链顶（第 15 级），其余书院**随机排列**；标题随之变为合成大"XX"（选择前为「合成大书院」），棋盘背景变为以该书院院徽颜色为主色调的淡雅渐变；对局中可随时点「换目标」（可取消）；
- 左右拖动 / 鼠标移动瞄准，松手落下；
- 两个同级书院相碰 → 合成更大一级书院并得分（合成出目标书院 +3000，触发全屏庆祝）；
- 顶部投放池随合成进度解锁（合成出某级即解锁投放该级），但**可投最大球不超过最大球的一半**（半径 ≤57.7，即最高投到 r=53 那级）——更大的书院只能靠合成获得；
- 院徽堆积越过红色警戒线 1.35 秒 → 游戏结束（逐个爆裂动效）；
- 右上角可静音 / 重开（重开需二次确认）；最高分本地保存。

徽章的图案偏移与缩放已**烤进徽章 PNG 文件**（`make-badges.ps1` 的 `$tweaks` 表：致理 25px 上移、日新/秀钟 30px、笃实 28px；探微/行健内容盒 0.70、未央 0.74、秀钟 0.92、至善 0.64，其余 0.86，无穹/水木 0.80），对小球、选择器、结算卡全场景生效且不会让贴图与球底白圆错位；主色调（`$colors` 表与 `game-config.js`）：日新橙、探微/为先/自强紫、行健/秀钟深蓝、笃实天蓝、求真/至善红。
